# Snake Water Gun Game

A simple command-line game built using Python where the user plays Snake, Water, and Gun against the computer.

## Features
- Random computer choices.
- User input for Snake, Water, and Gun.
- Automatic winner determination.
- Draw detection.

## Technologies Used
- Python
- Random module

## How to Run

1. Clone the repository:

   ```
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```
   cd snake_water_gun_game
   ```

3. Run the game:

   ```
   python main.py
   ```

## Game Rules

| Choice | Value |
|---|---:|
| Snake | 1 |
| Water | -1 |
| Gun | 0 |

- Snake beats Water.
- Water beats Gun.
- Gun beats Snake.
